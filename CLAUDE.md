# CLAUDE.md

## Giới thiệu project

Đây là project thực hành học Claude Code của Steven. Mục đích của project là học cách xây dựng website bằng Claude Code.

## Quy tắc làm việc

- Ngôn ngữ giao diện của website là **tiếng Việt**.
- Khi chỉnh sửa code, phải cố gắng **giữ nguyên những chức năng đang hoạt động**.
- **Không tự ý xóa file** hoặc thay đổi nội dung không liên quan đến yêu cầu.
- Sau mỗi thay đổi quan trọng, cần **kiểm tra Preview** để xác nhận thay đổi hoạt động đúng.
- **Mọi tiêu đề chính của website phải dùng chữ màu xanh lá.**
